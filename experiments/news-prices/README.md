# KAMIS 기사·수급 자료 보정

2021년 7월부터 2026년 6월까지의 KAMIS 소매가격을 사용한다. 2021년 7월은 직전 달 가격이 없어 가격 비교에 사용할 수 없으며, 첫 학습 대상 월은 2021년 8월이다. 2023년 이후에는 기존 가격 모델이 해당 월 전에 산출한 검증용 예측을 재사용한다. 그보다 이른 달에는 같은 입력과 전월·과거 동월 가격 대체 로직을 사용해 당시의 예측을 계산한다.

- `events.csv`는 기사와 보도자료 목록이다. 기사 제목의 가격 등락만으로 방향을 주지 않고, 출하 감소·재고 부족에는 `+1`, 출하 확대·재고 증가나 소비 감소에는 `−1`을 부여했다. 자재비 상승 등 해당 품목의 단기 소매가 방향이 불확실한 사례는 `0`이다.
- `reports.csv`는 한국농촌경제연구원 양념채소·과채 월보의 발행일, 품목, 원문 PDF, 해당 페이지를 남긴 목록이다. 오이·애호박·대파는 출하량, 양파·마늘은 재고·입고·생산량을 사용한다. 텍스트에서 발행일과 해당 품목의 방향을 함께 확인할 수 있는 사례를 추출했다. 이미지 전용이나 방향 판단이 어려운 보고서는 포함하지 않았다.

선택한 월에는 직전 달 발행 자료만 사용한다. 뉴스 방향은 품목별 평균, 월보 방향은 가장 최근 자료를 사용한다. 두 신호의 보정 계수는 기존 예측과 실제값의 로그 차이에 정규화 회귀를 적용해 각각 추정한다. 신호 방향을 뒤집는 결과에는 계수 0을 적용하며, 월보 계수는 이번 학습에서 0으로 추정됐다. 신호가 없을 때는 기존 가격 예측을 사용한다.

검증 결과는 2026년 1~6월을 대상으로 하며, 매 대상 월 전에 관측된 실제 가격으로만 계수를 추정한다. 서비스용 계수는 2026년 6월까지 전체 자료로 다시 학습했다. 검증용 예측은 각 대상 월보다 앞선 데이터로 계산한다. 수집 기간은 확인 가능한 원문의 범위이며, 뉴스 수집은 자동으로 갱신되지 않는다.

저장소 루트에서 NumPy, pandas, SciPy가 있는 환경으로 실행한다.

```bash
python scripts/evaluate-kamis-news.py --output /tmp/kamis-news --export-site
```

`summary.json`에는 학습·검증 표본과 오차, `holdout-prices.csv`에는 품목·월별 예측값과 실측·출처가 있다. `--export-site`는 웹앱에서 사용할 월별 계수와 출처를 생성한다.
